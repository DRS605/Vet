Checklist de instalaciónFase 1 · PC de la clínica (Windows + Docker)

Antes de salir — llevar

  • Docker Desktop (instalable o ya instalado en el PC)
  • Datos SMTP del correo de la clínica: servidor, puerto (587), usuario, contraseña
  • Nombre y NIF de la clínica
  • Email + contraseña para el usuario administrador
  • La carpeta del proyecto (repo Vet) y Python 3 en el PC o en tu portátil

Datos a apuntar (al terminar)

IP del PC (ipconfig): _______________________
Acceso clínica: http://______:8080/vet.html
Admin — email: _______________________
Admin — contraseña: _________________
Fecha instalación: ____ / ____ / 2026

1 Preparar el equipo

  • Instalar Docker Desktop y abrirlo (icono en verde “running”). En Ajustes → General, marca “Start Docker Desktop when you log in” para que arranque solo.
  • Copiar la carpeta del proyecto al PC (p. ej. C:\ALXORVet). Abrir una terminal ahí (PowerShell o CMD).

2 Configurar

  • Crear el fichero de config: copiar el ejemplo y abrirlo con el Bloc de notas:
copy despliegue\.env.ejemplo despliegue\.env notepad despliegue\.env
  • Rellenar en .env: POSTGRES_PASSWORD (una robusta), JWT_CLAVE_SECRETA (larga y aleatoria), y el correo → CORREO_HABILITADO=true, CORREO_HOST, CORREO_PUERTO=587, CORREO_USUARIO, CORREO_CLAVE, CORREO_REMITENTE. (Gmail/Workspace: usa una “contraseña de aplicación”.)

3 Arrancar

docker compose -f despliegue\docker-compose.produccion.yml --env-file despliegue\.env up -d --build
  • Esperar 1-2 min. Comprobar que hay 2 contenedores en marcha: alxor-vet-api y alxor-vet-postgres.

4 Crear la clínica (arranque limpio + cuadro vacunal)

set CLINICA_NOMBRE=Nombre de la clínica set CLINICA_NIF=B12345674 set ADMIN_EMAIL=admin@clinica.com set ADMIN_PASSWORD=UnaClaveFuerte1! python scripts\inicializar-clinica.py
  • En PowerShell usa $env:CLINICA_NOMBRE="…" en vez de set. Crea la clínica, el admin y carga las pautas vacunales por especie. Sin clientes ni animales.

5 Comprobar

  • Abrir http://localhost:8080/vet.html → entrar con el admin.
  • Menú Vacunas: se ven las pautas (perro, gato, conejo, hurón).
  • Crear un cliente + animal de prueba, y en Recordatorios enviar uno para confirmar que el correo sale (revisar bandeja del destinatario).
  • ipconfig → anotar la IP del PC. Desde otro equipo de la clínica: http://<IP>:8080/vet.html.
  • Copia de seguridad (guárdala en una carpeta que respalden):
docker exec alxor-vet-postgres pg_dump -U postgres alxor > backup.sql
Cartilla Viva (portal del dueño): es FASE 2. Con instalación local no se activa; requiere publicar la app en internet. Todo lo demás (agenda, historial, vacunas, recordatorios por correo, facturación) funciona en esta fase.

? Si algo falla

  • ✕
    No arranca / “Docker not running” → abrir Docker Desktop y esperar a “running”; reintentar el up -d.
  • ✕
    Puerto 8080 ocupado → cambiar PUERTO_LAN en .env (p. ej. 8090) y up -d otra vez.
  • ✕
    El correo no sale → revisar Host/usuario/contraseña, puerto 587 con STARTTLS, y en Gmail una contraseña de aplicación. Ver logs: docker logs alxor-vet-api.
  • ✕
    No se accede desde otro PC → mismo wifi/red y permitir el puerto en el Firewall de Windows (red privada).
